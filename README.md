# NutriMap AI

Personalized health-aware recipe recommendation system.

## Recommendation pipeline
1. Available ingredient compatibility
2. Diet preference filter
3. Allergy filter
4. TF-IDF + cosine similarity
5. Health-condition nutrition mapping
6. Health-goal nutrition mapping
7. Combined NutriMap score
8. Top recipe recommendations
9. Dynamic 7-day meal plan

The health mapping is a student-project decision-support layer, not medical diagnosis. The curated catalogue currently does not store sodium, so hypertension ranking does not claim sodium-specific filtering.
